Conduit RealWorld Automation Framework 🚀
This repository contains a professional automation framework for the Conduit (RealWorld) application, developed as part of my graduation project. It demonstrates a modern approach to QA Automation using Vibe Coding methodologies to achieve speed and reliability.

🛠 Tech Stack
Language: Python 3.x

Framework: Pytest

Tool: Selenium WebDriver

Architecture: Page Object Model (POM)

✨ Key Features
Hybrid Testing Strategy: Integration of UI and API layers for efficient test execution.

AI-Augmented Scaffolding: Utilized AI tools (Vibe Coding) to accelerate framework setup and focus on complex test logic.

Comprehensive Coverage: Includes tests for user authentication, article management, and basic security checks (XSS/SQLi).

Robust Design: Custom wait strategies and clean, modular code structure.

🚀 How to Run
Clone the repo: git clone https://github.com/StasLisson/project3.git

Install dependencies: pip install -r requirements.txt

Execute tests: pytest
